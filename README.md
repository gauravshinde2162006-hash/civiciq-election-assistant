# CivicIQ — Election Process Assistant

CivicIQ is an intelligent election process assistant designed to help voters understand registration requirements, voting procedures, eligibility criteria, and important deadlines across all U.S. states and Indian states. Built with Flask and powered by Claude AI or Groq LLaMA, it provides state-specific, accurate election information through a conversational interface.

## Tech Stack

- **Backend:** Python Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **AI/LLM:** Claude AI / Groq LLaMA
- **Deployment:** Docker, Google Cloud Run

## How to Run Locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the Flask app:
   ```bash
   python app.py
   ```

3. Open your browser to **http://127.0.0.1:5000**
